# Repositorio_Airbnb
Clonacion de aplicacion de Airbnb para el extra de computo mobil y/o taller integrador

INSTRUCCIONES PARA EL FUNCIONAMIENTO CORRECTO DEL PROYECTO.

Para que les funcione el proyecto deben de instalar las dependencias composer dentro de airbnb-backend,
y las dependencias npm en el airbnb-frontend para que pueda funcionar el proyecto completo
Para ensender el servidor artisan en backend nesesitan ingresar el comando **php artisan serve** 
y para ensender el frontend ingresar el comando **npm run dev**.
Cada uno ingresarlo cuando esten en la carpeta determinada del servidor que quieren encender.







Si tiene un clon local, puede actualizarlo ejecutando los siguientes comandos.
git branch -m main móvil
git fetch origen
git branch -u origen/mobil mobil
git remoto set-head origen -a
